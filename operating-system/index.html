Our work/Operating system

We run on the system we write about.

At our operating company, agents brief the leadership team every weekday at 6am. They read the CRM, the support desk, product usage, the books and the market, then write reports that take a position, show their sources and recommend the next move. People make the calls.

Anatomy of a report

Built to be argued with.

Every report is laid out so a reader can disagree with it quickly: the claim first, then the evidence, then where the evidence came from.

1 2 3 4 5
  1. 1
    The verdictIt opens with a position, not a summary. If the week was bad, the first line says so.
  2. 2
    What it readThe time it read the data, how many sources it covered, and a flag when one of them is partial.
  3. 3
    Vital signsThis week against last, with the normal range where one exists, so a dip in season reads as a dip in season.
  4. 4
    Three things that matterRanked, each traced to the report it came from, each ending in what it means for the week.
  5. 5
    The source recordEvery section opens to the structured record behind it. Nothing on the page is unsourced.

How it stays honest

The harness does the work the model can’t.

A model writes well. Whether its report deserves trust depends on everything around it: what it may read, what it must check, and what happens when it’s wrong.

  1. 01Read

    Agents query the live systems directly, under versioned prompts, and write a structured record rather than free text.

  2. 02Check

    Validators fail closed. A missing source or a broken contract stops the report instead of letting it guess.

  3. 03Publish

    Reports land before the workday starts, each carrying its own freshness and coverage line.

  4. 04Grade

    Every Friday an editorial retro scores the week’s reports. The CEO adds feedback of his own.

  5. 05Remember

    That feedback is stored and read by the next run, so the same miss doesn’t repeat.

Then Monday starts again, a little sharper. Changes to the report templates run against a fixed set of test cases before they ship.

It recommends. People decide.

Every action has a human owner. Drafted notes wait for a person to send them.

It says what it couldn’t see.

A partial source is flagged on the page, and an empty section stays empty rather than guessed.
